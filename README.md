# 组件展示

Flutter UI 组件库与交互预览 APK。

## 组件

- 组件目录与搜索
- 按钮、开关、分段选择
- 数值步进、滑块、输入框、颜色选择
- 键帽、鼠标按钮、手柄按键、触控位置拖拽
- 列表、绑定、配置与主题
- 液态玻璃、导航镜片及页面过渡

## 构建

GitHub Actions 运行静态分析、组件测试和 ARM64 Release APK 构建；产物在 Artifacts 中提供。

## Axon 原生源码 UI 控件扩展

基于 Axon-Input 真实 Java 声明新增六组可独立复用的 UI-only 控件：手柄兼容/交换、触控区域拖拽、超级自定义控件、悬浮媒体、快捷键绑定、五槽位工作区。所有交互只更新 Flutter 本地状态，无设备输入、视频播放或原生配置写入。键显与其他分页增加了入口，主页增加精选预览卡。
