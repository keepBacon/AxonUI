# AxonUI

Flutter/Dart Material 3 UI-only component library for Axon Input, styled after FlClash. This project contains UI controls, previews and demo-only state; it does not implement keyboard/mouse injection, gamepad hooks or native input.

Build Android APK with `.github/workflows/build-apk.yml` via GitHub Actions. Artifact: `Axon-FlClash-UI-only-ARM64-*`.
