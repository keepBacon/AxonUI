# Axon UI Lab — preview APK design contract

## Product boundary

- This is a **Flutter/Dart component showcase**, not FlClash, Axon Input or a functioning input engine.
- FlClash is not used as a layout reference. Existing GPL-3.0 glass shader files are retained strictly as reusable visual material. The app has its own header, segmented workspaces and component catalogue.
- No input interception, keyboard sending, gamepad listening, touch injection, network proxy, root, Shizuku, or device permissions are added.

## Axon original control coverage

Original source: `Axon_BuildFix190_FlClashStyle_NativeUI_FullSource.zip`.

- `AxonFlClashKit.java`: setting rows, grouped cards, switches, segmented selections, chips, sliders, button variants, inputs, metrics, progress.
- `PluginUiSpec.java`: `feature.toggle` and `feature.button`; nine debug types `slider`, `color`, `select`, `number`, `text`, `key`, `toggle`, `list`, `binding`.
- Axon interaction surface: keyboard keycaps, mouse buttons, gamepad face and directional controls, visual touch region editor, press/size/opacity/ripple demonstrations. All use Flutter local state.

## Navigation

1. **组件库**: searchable categories, live feedback and previews.
2. **Axon 控件**: reusable input-style primitives and declarative plugin-control catalogue.
3. **布局编辑**: draggable purely visual key layout, gamepad button response, sliders.
4. **材质动效**: appearance, glass tiers, shader material sample and colors.

## Build contract

- Android ARM64 APK generated by GitHub Actions.
- `flutter analyze --no-fatal-infos` + `flutter test` must pass before release build.
- Gallery tests must not depend on FlClash network data or material layout.
